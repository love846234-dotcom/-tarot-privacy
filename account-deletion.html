이 페이지는 도깨비 앱을 설치하거나 앱에 접속하지 않고도, 연결한 계정과 그에 딸린 서버 데이터의 삭제를 요청할 수 있는 곳입니다. 앱을 갖고 계신 분은 앱 안의 [전체 메뉴 → 설정·계정 → 계정 삭제]에서도 같은 처리를 바로 받을 수 있습니다.

1. 계정 삭제 요청 방법

아래 이메일로 ① 가입에 쓰신 방법(Google 또는 Kakao)과 ② 그 계정의 이메일 주소 두 가지를 적어 보내 주세요.

contact@brighttale.co.kr 으로 삭제 요청 메일 쓰기

본인 확인을 위해 알려주신 이메일로 확인 회신을 드릴 수 있습니다. 회신 없이 처리가 끝나면 별도 안내 없이 종료될 수 있습니다.

2. 삭제되는 서버 데이터

요청을 확인하면 아래 값을 서버에서 영구히 지웁니다(앱 안 삭제와 완전히 같은 범위입니다):

항목설명
이메일 주소로그인 시 제공받아 서버에 저장해 둔 값
이름/닉네임로그인 시 제공받아 서버에 저장해 둔 값
소셜 로그인 고유 IDGoogle 또는 Kakao 계정을 구분하는 값 그 자체
기기 간 동기화 값은화 잔액 · 연속 출석 일수 · 마지막 방문일(로그인한 계정에 묶어 기기를 바꿔도 이어지게 했던 값)

3. 삭제되지 않는 것 — 기기(휴대폰) 안의 데이터

상담 기록·고민저장소·인연(별명·관계)·비밀 메모·타로 리딩 기록 등은 계정 삭제와 무관합니다. 이 값들은 로그인 여부와 상관없이 처음부터 이용자의 기기 안에만 저장되고 저희 서버로 전송된 적이 없기 때문에(개인정보처리방침 3-1항 참고), 계정을 삭제해도 서버에서 지울 대상 자체가 없습니다 — 그대로 기기에 남습니다.

이 기기 안 데이터까지 함께 지우려면 계정 삭제와는 별개로, 안드로이드 [설정 → 애플리케이션 → 도깨비 → 저장공간 → 데이터 삭제] 또는 앱 삭제를 이용해 주세요.

4. 요청 처리 방법

보내주신 이메일을 사람이 직접 확인하고, 알려주신 로그인 방법·이메일과 일치하는 계정 기록을 찾아 서버에서 제거합니다. 처리가 끝나면 별도 통지 없이 종료될 수 있으며, 확인이 필요한 경우 답장으로 다시 안내드립니다.

5. 다른 개인정보 관련 문의

계정 삭제 외의 개인정보 관련 문의도 같은 주소 (contact@brighttale.co.kr)로 받습니다. 자세한 수집· 이용·보관 내용은 개인정보처리방침을 참고해 주세요.
